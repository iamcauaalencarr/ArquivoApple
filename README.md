# Arquivo Apple

Acervo visual de iPhones, organizado por modelo e cor.

**55 modelos · 219 combinações de modelo e cor · 418 imagens individuais e alternativas.** Inclui também 55 imagens gerais com as cores de cada modelo.

## Galeria

Abra [index.html](index.html) no navegador. Cada cartão começa mostrando todas as cores; clique nos seletores para ver uma cor específica e em **Todas** para voltar. Inclui busca por modelo ou cor e filtro por ano. Funciona localmente, sem instalação ou servidor.

## Organização

- `index.html` e `galeria.html`: galeria interativa.
- `iphone-*/cor/`: imagens e registros de origem por acabamento.
- `iphone-*/todas-as-cores.*`: imagem geral do modelo.
- `catalogo-galeria.json`: dados dos cartões e seletores.
- `indice.json` e `indice.csv`: catálogo de cores e imagens.
- `dimensoes.csv`: dimensões das imagens individuais e alternativas.
- `fonte.json` e `fonte-produto.json`: registros de origem dentro das pastas.
